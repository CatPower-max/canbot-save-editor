깡통봇 로컬 에디터 CanBot local editor

Termux(안드로이드)나 PC에서 직접 실행하는 깡통봇 에디터입니다. 인계 코드로 불러오거나, 루팅된 기기·에뮬레이터의 SAVE 파일을 바로 고칠 수 있습니다. 저장 횟수와 편집 한도는 디스코드·웹과 똑같이 적용됩니다.

Run CanBot's editor on Termux (Android) or a PC. Load with transfer codes, or edit the SAVE file of a rooted phone or emulator. SAVE allowance and edit limits are the same as on Discord and the website.

1. 토큰 Token

디스코드로 로그인하면 토큰을 받을 수 있습니다. 깡통봇 서버의 인증된 멤버만 받을 수 있습니다.

디스코드로 로그인 / Sign in with Discord

이 토큰은 지금 한 번만 보입니다. 다른 사람에게 보여 주지 마세요. Shown only once. Keep it private.

2. 설치 Install

Termux (안드로이드, F-Droid에서 설치) · Linux · macOS — 한 줄 설치 후 canbot 만 입력하면 됩니다.

pkg install nodejs
curl -fsSL https://canbot.dev/local/install.sh | sh
canbot

One-line install, then just run canbot. It refreshes itself from canbot.dev (at most every 6 hours).

Windows (Node.js 18 이상): canbot.js 내려받기 후 node canbot.js

처음 실행할 때 위 토큰을 붙여 넣습니다. 토큰과 백업은 ~/.canbot 폴더에 저장됩니다.

3. 알아 둘 것 Good to know

  • 인계 코드는 업로드할 때만 새 코드로 바뀝니다. 업로드하기 전에 나가면 같은 코드를 게임에서 그대로 쓸 수 있습니다.
  • 업로드 결과를 확인할 수 없으면 자동으로 다시 시도하지 않습니다. 편집한 SAVE는 백업 폴더에 남습니다.
  • SAVE 파일 모드는 루트 권한(su)이 필요하고, 고치기 전에 원본을 백업합니다. 게임을 완전히 종료한 뒤 사용하세요.
  • SAVE, 인계 코드, 편집 내용은 canbot.dev로 보내지 않습니다. 서버는 토큰 확인, 게임 데이터, 저장 횟수만 다룹니다.
